## Overview

Accessibility standards ensure AI systems are usable by everyone, regardless of ability, technology, or context. AI interfaces introduce unique accessibility challenges: dynamically generated content that screen readers weren't designed for, complex multi-step workflows requiring keyboard navigation, overwhelming cognitive load from non-deterministic outputs, and visual-only feedback for processing states.

These standards address the full spectrum of accessibility needs: assistive technology compatibility (screen readers, keyboard navigation, voice control), cognitive accessibility (reducing mental effort, managing complexity), and inclusive design (supporting diverse users in diverse contexts). The goal is not compliance checkboxes but genuinely usable AI experiences for people with disabilities, neurodivergent users, aging populations, and anyone experiencing temporary or situational limitations.

Good accessibility benefits everyone: clear focus management helps power users, reduced cognitive load helps stressed users, keyboard shortcuts accelerate workflows, and semantic markup improves SEO and maintainability. These standards provide the technical implementation and design strategies to make AI features truly inclusive.

---
## Key Principles
1. **Perceivable** - AI activity, outputs, and states must be perceivable through multiple senses
2. **Operable** - All AI functionality must be operable via keyboard, screen reader, voice, and other assistive technologies
3. **Understandable** - AI behavior must be predictable, interfaces must be learnable, complexity must be managed
4. **Robust** - AI features must work reliably across assistive technologies and adaptive devices
5. **Inclusive by default** - Accessibility is not an add-on but integral to AI design from the start
6. **Progressive enhancement** - Core AI value accessible to all, enhanced experiences for capable devices
---
## When to use these standards
- **All AI features** - Accessibility is not optional (legal compliance: WCAG 2.1 AA, ADA, Section 508)
- **Dynamic AI content** - Streaming text, real-time updates, generated results
- **Complex AI workflows** - Multi-step processes, conversational interfaces, wizards
- **AI configuration** - Settings panels, tuning controls, advanced options
- **AI feedback** - Processing states, progress indicators, error messages
- **Multimodal AI** - Combining text, visuals, audio, and interaction modalities
---
## Related Categories
- **Error handling**: Accessible error messages and recovery paths
- **Conversation**: Multi-turn chat interfaces need robust accessibility
- **Governors**: Human oversight standards must be keyboard accessible
- **Identifiers and branding**: Visual AI indicators need text alternatives
- **Input and authoring**: AI prompt interfaces must support assistive technologies
- **Generation and output**: AI results must be perceivable and navigable
