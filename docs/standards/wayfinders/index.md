## Overview

Wayfinders are standards that orient users within AI systems. They help answer fundamental questions like "What can this AI do?", "Where am I?", and "What should I try?". These standards are especially critical for first-time users or when introducing new AI capabilities.

Good wayfinding standards reduce cognitive load by making AI capabilities discoverable and understandable. They help users build accurate mental models of what the AI can and cannot do, preventing frustration from unmet expectations.

---
## Key Principles
1. **Make capabilities visible** - Don't hide what the AI can do behind a blank canvas
2. **Provide contextual guidance** - Show relevant options based on user context
3. **Progressive disclosure** - Reveal complexity gradually as users gain expertise
4. **Clear entry points** - Make it obvious how to start using AI features
5. **Predictable navigation** - Use consistent patterns for moving through AI experiences
---
## When to use these standards
- **Onboarding new users** to AI features
- **Empty states** where users need to take first actions
- **Complex AI systems** with multiple capabilities
- **Contextual features** that appear based on user activity
- **Discovery moments** where AI can add unexpected value
---
## Related Categories
- **Input and authoring**: Once users know what's possible, these standards help them craft effective prompts
- **Conversation**: Many conversational AI systems use wayfinders to guide dialogue
- **Trust builders**: Clear wayfinding builds trust by setting accurate expectations
